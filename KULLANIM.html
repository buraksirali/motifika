4. Kameranın Açılışı

Hâlâ hiçbir pencere yok. Şimdi USB ya da CSI kameraya gerçek anlamda bağlanılıyor. Kamera başka uygulama tarafından tutuluyorsa burada ölünür.

app/main.py · 128 provider, cap, frame_size = open_camera_or_image(args)

open_camera_or_image — açılışın iç yüzü

app/main.py · 69-93 if args.image: # test modu img = cv2.imread(args.image) return (lambda: img.copy()), None, (W, H) cap = cv2.VideoCapture(args.camera) # /dev/video0 if not cap.isOpened(): raise RuntimeError("kamera açılamadı") cap.set(CAP_PROP_FRAME_WIDTH, 1280) cap.set(CAP_PROP_FRAME_HEIGHT, 720) def provider(): ok, frame = cap.read() return frame if ok else None real_w = int(cap.get(CAP_PROP_FRAME_WIDTH)) # gerçek değeri sor real_h = int(cap.get(CAP_PROP_FRAME_HEIGHT)) return provider, cap, (real_w, real_h)

Kamera nasıl açılıyor — zincir

cv2.VideoCapture(0) | v V4L2 sürücüsü (Linux Video for Linux 2) | v /dev/video0 (kernel aygıt düğümü) | v USB webcam ya da Pi CSI kamera
Hata olabilecek noktalar:
  • /dev/video0 yok — aygıt takılı değil ya da yanlış indeks
  • Kullanıcı video grubunda değil — izin reddedildi
  • Başka uygulama (örn. Cheese) kamerayı tutuyor — cap.isOpened() False
İncelik: cap.set(WIDTH, 1280) kameraya rica gönderir; kamera desteklemiyorsa sessizce en yakını verir. Bu yüzden hemen sonrası cap.get(...) ile gerçek boyut geri okunur. Kalibrasyon homography'si bu boyuta bağlı; yanlış sayı kullanılırsa eşleşme bozulur.

provider nedir, ne işe yarar?

provider bir kapanış (closure) — her çağrıldığında bir BGR kare döndürür. Diğer modüller kameranın gerçek olup olmadığını bilmek zorunda değil; provider() arabirimine bakar.

Sonuç
Kamera açıldı, çözünürlük ayarlandı, provider hazır. Hâlâ hiçbir pencere yok — ekrana gösterim daha sonra.

9. Kullanıcı Dokurken — canlı tespit

Kullanıcı kilim dokuyor; eli atkı ipliğini sıraya yerleştiriyor. Kameranın gördüğü değişiyor. Her karede ne oluyor?

Kullanıcı
Bir sıraya iplik koymaya devam ediyor; eller kameraya görünür halde.

Adım 1: Kareyi düzleştir

app/progress.py · 90-108 scale = np.array([[12,0,0], [0,12,0], [0,0,1]]) M = scale @ H_cam_to_chart # tek matriste birleştir out_size = (cols * 12, rows * 12) warped = cv2.warpPerspective(frame, M, out_size, INTER_LINEAR)

Kameradaki yamuk perspektif düzleşir. Kuş bakışı görüntü çıkar — kilim sanki üstten dik bakılmış gibi. Boyut cols*12 × rows*12 piksel.

Adım 2: Her sıraya bir skor ver

app/progress.py · 111-155 gray = cv2.cvtColor(warped, COLOR_BGR2GRAY) for r in range(rows): band = gray[r*12 : (r+1)*12] # o sıranın şeridi std_h = float(band.std()) # varyans darkness = 1.0 - float(band.mean()) / 255.0 scores[r] = 0.6 * std_h / 80.0 + 0.4 * darkness

Sezgi: boş kilim = açık çözgü ipi = tek tonda → varyans düşük, parlaklık yüksek. Dokunmuş = renkli iplikler → varyans yüksek, koyu. İkisinin karışımı (0.6 ve 0.4 ağırlık) güvenilir bir skor verir.

Adım 3: Yumuşat (EMA)

app/progress.py · 167-175 score_ema = 0.4 * scores + 0.6 * old_ema

Anlık skorda titreşim olur (gölge, el geçiyor, kamera shake). EMA bu titreşimi süzer; trendi korur.

Adım 4: Eşik geçişini bul

app/progress.py · 188-220 peak = score_ema.max() threshold = peak * 0.55 woven = score_ema >= threshold # bool dizi if direction == "bottom_up": idxs = np.where(woven)[0] auto_row = int(idxs.min()) - 1 # bir üstü = aktif auto_row = max(-1, auto_row)

Bottom-up'ta dokuma alttan başlar; en yukarıdaki "dokunmuş" sıra = son tamamlanan; bir üstü = aktif sıra. Top-down'da ters.

Sonuç

12. Çıkış — kaynaklar serbest bırakılır

Sebep ne olursa olsun (kullanıcı çıktı, hata oldu, kamera koptu) kamera ve pencereler düzgün kapanmalı. Aksi halde kamera kilitli kalır.

app/main.py · 246-250 finally: if cap is not None: cap.release() cv2.destroyAllWindows()

finally Neden Önemli?

try/finally blokları Python'a "bu blok ne olursa olsun çalışsın" der — break, return, exception, hatta SystemExit bile finally'yi atlatamaz.

Çıkış sebebifinally çalışır mı?
q tuşu (break)Evet
Kamera koptu (provider None döner, break)Evet
Beklenmedik exception (warp boyutu uymaz vs.)Evet
Ctrl+C (KeyboardInterrupt)Evet
Kill -9Hayır (sürecin başına çare yok)

cap.release() ne yapıyor?

V4L2 sürücüsüne "kamerayı bırakıyorum" der; /dev/video0 aygıtı serbest kalır, başka uygulama (veya bir sonraki çalıştırma) kullanabilir.

release çağrılmazsa: Kamera bazı sistemlerde 30+ saniye kilitli kalabilir. Yeni çalıştırmada "kamera açılamadı" hatası alırsın. finally bloğu bu yüzden var.

destroyAllWindows ne yapıyor?

OpenCV'nin açtığı tüm pencereleri kapatır. cv2.namedWindow ile açılan her pencere bu sırada yok edilir.
